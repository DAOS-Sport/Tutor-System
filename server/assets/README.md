# server/assets

寄信用的產品素材。**不是**使用者上傳物 —— 那些走 `objectStorage`（`/uploads/*`）。

## parent_guide.png

家長對帳成功通知信裡內嵌的「新家教系統使用說明」海報。

- 以 `cid:` 內嵌在信件本文，取代原本的「點擊登入家教系統」按鈕。
- 之所以不用按鈕：`liff.line.me` 深連結只有在 LINE App 內開啟才會自動登入，
  從 Email 點會落在一般瀏覽器，行為不保證。海報教的是
  「加入場館官方帳號 → 圖文選單『家教班』」，那才是走得通的路。
- **檔案不存在時信照樣寄出**，只是退回按鈕版。不會因為缺一個素材就發不出通知。
- 路徑可用環境變數 `PARENT_GUIDE_IMAGE` 覆寫。
- 建議寬度 1200px 以內、檔案 1MB 以內（附件會計入信件大小，Gmail 上限 25MB）。
