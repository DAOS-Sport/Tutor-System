先認識家長畫面

從公司提供的家長入口登入。主要功能都在畫面下方。

介面什麼時候用
首頁選課程品項，開始報名。
我的課程補付款資料、看審核狀態與剩餘堂數、上課簽到。
個人查看與管理家長、學員資料。
聊天目前顯示「敬請期待」。請用原本的聯絡方式找教練或櫃台。
每次上課：家長先簽到 → 出示畫面給櫃台確認堂數 → 再進場。

① 一般報名

同一家庭的學員報名

去這裡 → 首頁 → 品項 → 場館 → 教練
  1. 選擇要上的課程品項，例如一對一、一對二。
  2. 選擇場館，再選擇教練。已有指定教練時，先確認可以上課及購買堂數。
  3. 在「課程報名」選擇購買期數、上課學員，核對費用。
  4. 按「下一步：填寫轉帳資料」，依付款頁指示轉帳。
和不同家庭一起上課，請使用「發起團購」，讓另一位家長用自己的帳號加入。

② 轉帳、上傳、等對帳

去這裡 → 付款資訊
稍後補資料 → 我的課程 → 上傳付款資料
  1. 核對應繳金額、戶名與轉帳帳號，完成轉帳並保留憑證。
  2. 回到系統，填寫轉帳卡片末 5 碼。
  3. 上傳轉帳證明截圖，按「確認無誤，送出付款資料」。
  4. 等待櫃台對帳、確認開通。可回「我的課程」查看狀態。
已轉帳仍要回系統送出資料。看到「待對帳」時先等櫃台確認，不用重複報名或再次付款。

畫面中的金額與銀行資料僅供辨識位置；匯款請看您自己的付款頁。

③ 不同家庭一起報名

朋友、同學等不同家庭合上一班

去這裡 → 選好品項、場館、教練 → 課程報名 → 發起團購
  1. 第一位家長：按「發起團購」，選自己家的學員與購買期數，建立團購。
  2. 在團購狀態頁按「分享邀請」，把加入連結傳給另一位家長。
  3. 另一位家長：用自己的帳號開啟連結，選自己家的學員，完成加入。
  4. 每個家庭各自依自己的應繳金額轉帳，填末 5 碼、上傳憑證並送出付款資料。
  5. 等人數及全團付款資料齊備，再依畫面提示送審；滿團且資料齊備時會自動送審。
  6. 等待櫃台審核與對帳，確認課程開通。
送審後名單會鎖定。人數或付款資料還沒齊，先請其他家長完成；需更改已送出的資料，請找櫃台。

④ 選「待分配」怎麼做

去這裡 → 選擇教練 → 待分配
  1. 選「待分配」，完成報名、轉帳與憑證上傳。
  2. 向上課場館的櫃台提出媒合需求（點此選擇場館 LINE），提供學員、場館及可上課時段。
  3. 櫃台會依教練可配合的時間協助媒合，請等待安排通知。
付款完成不代表已配到教練或確定上課時間。請等櫃台確認媒合結果，再與教練約課。

⑤ 每次上課前都要做

去這裡 → 我的課程 → 找到本次課程 → 今日上課簽到
  1. 在實際上課當天打開課程，確認教練、學員與剩餘堂數。
  2. 按「今日上課簽到」，核對視窗內容後按「簽到」。
  3. 完成後，把系統畫面出示給櫃台確認堂數。
  4. 櫃台確認後，再進場上課。
簽到會使用課程堂數。不是試按鈕；簽錯、堂數不符或無法簽到，請先找櫃台處理。

團購共享課程請先協調當次簽到，由櫃台確認，避免各家庭重複操作。

沒有自動開啟 LINE？請在 LINE 搜尋上方 ID（包含 @）。聯絡時請提供學員姓名及問題；付款查詢可一併提供訂單編號。

資料送出了，還顯示待對帳？

請等待櫃台核對。若需查詢，提供學員姓名、訂單或付款單編號及匯款證明。

按鈕灰色、沒有簽到入口？

先確認資料是否填齊、課程是否已開通。若仍無法操作，請將畫面提供給櫃台協助。

教練有開放線上預約時段？

若課程採預約制，依教練通知選擇可預約時段；找不到時段請直接與教練確認。
