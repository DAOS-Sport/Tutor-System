流程總覽

先看整個流程，再點選下方目錄，前往想了解的步驟。

  1. 1確認報名狀態查看名單、對帳與剩餘堂數
  2. 2協調上課時間與家長約課，需要時申請預約制
  3. 3上課前提醒家長簽到 → 櫃台確認 → 進場
  4. 4查看授課記錄查簽到，依課程要求填寫內容

① 首頁：今天有哪些課

去這裡 → 下方「首頁」
  1. 確認今天日期與今日課程。
  2. 有課程時，點入對應課程，查看時間、場館與學員。
  3. 若採自助簽到制，仍請按您與家長約定的時間上課。
畫面顯示「今日沒有課程」，表示系統當天沒有列出課程；請再對照您與家長的約課安排。

② 報名記錄：看報名與堂數

去這裡 → 下方「報名記錄」
  1. 用全部、進行中、剛報名待對帳、已完成切換名單。
  2. 查看學員、家長、場館、課程期限與剩餘堂數。
  3. 團報可查看同班家庭與學員；需要確認付款或修改資料時，請找櫃台。
「剛報名待對帳」表示尚未完成櫃台對帳。請提醒家長完成付款資料，並由櫃台確認開通。

一筆是同一期的一張訂單，不是一次上課；下一期會是另一筆。

③ 排課：管理可上課時段

去這裡 → 下方「排課」
  1. 切換週／月，選日期範圍與場館，查看時段。
  2. 平常的上課時間、改期，由教練與家長直接協調。
  3. 想改用家長線上預約，先透過公司 LINE 400提出「預約制」需求。
  4. 經公司確認後，再開放可上課的時段，讓家長選擇預約。
先向公司確認使用模式，再設定時段；不要只憑畫面上的新增按鈕判斷已完成模式調整。
預約制確認後，如何開放時段？
  1. 按「＋ 新增槽位」。
  2. 選日期、開始時間與場館。
  3. 核對後按「建立槽位」。
  4. 有多個時段時可使用「批量新增」；建立後回總表確認。

「槽位」就是可供預約的上課時段。

④ 授課記錄：查上課與簽到

去這裡 → 下方「授課記錄」 → 點選一堂課
  1. 依日期區間、簽到狀態、學員篩選課程。
  2. 點入「授課入口」，查看學員及簽到狀況。
  3. 需要填寫課程內容時，使用「填寫課前規劃」或「填寫授課記錄」；依該課程開放功能與公司要求辦理。
教練端不提供代簽。請由家長在上課當天完成簽到；異常請交由櫃台處理。

⑤ 個人：更新教練介紹

去這裡 → 下方「個人」
  1. 查看教練資料與授權場館。
  2. 在「個人介紹」或「詳細介紹」旁按「編輯」，更新教學專長與介紹。
  3. 確認內容正確後，依畫面完成儲存。

家長會透過介紹認識您。聯絡資料、場館或權限有誤，請聯繫公司協助確認。

每次上課，提醒家長這三步

1 家長簽到→2 櫃台確認堂數→3 再進場上課

請提醒家長到「我的課程」完成當次簽到，把系統畫面出示給櫃台，確認堂數後才進場。

家長無法簽到、堂數不符或課程未開通：先請櫃台處理，再確認是否能上課。

可直接提醒家長：「上課前請先在系統簽到，再把畫面給櫃台確認堂數，確認後就可以進場囉。」
