新系統資料口徑比對表

三個建檔結構：① 整筆訂單創建 ② 家長資料 ③ 教練資料 — 供與舊系統資料逐欄比對

資料來源：本專案實際 PostgreSQL schema（啟動建表 / migration），每欄標註原始碼行號可核對

⚠️ 防幻覺聲明：本表所有欄位皆逐字取自下列原始碼檔案，未在程式碼中出現的欄位一律不列出，也未杜撰任何約束。可對照 檔案:行號 自行驗證。
來源檔案： db/migrations/002_admin_tables.sql、 server/bootstrap/admin.js、 server/bootstrap/coreSchema.js、 db/migrations/008_parent_profile_maintenance.sql。
PK 主鍵 UNIQUE 唯一 NN 必填 FK 外鍵 AUTO 系統產生·匯入勿供 DEFAULT 預設
最右欄「舊系統對應」可直接點擊輸入（瀏覽器內編輯，列印或截圖保存；重新整理不留存）。
