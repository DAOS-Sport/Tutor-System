# 家長／學員 使用手冊

## 一、開啟方式
1. **建議**：在 LINE 內點各場館官方帳號選單 → 自動開啟 LIFF（會自動登入，免輸帳密）。
2. **備案**：用瀏覽器開 `https://daos-tutoring-courses.replit.app/liff/#/`，需手動輸入手機。

> 第一次開啟手機畫面看到「正在載入」就請耐心等 1–3 秒，系統正在初始化。

## 二、首次註冊
1. 輸入手機號碼 → 系統查不到 → 跳到「註冊」頁。
2. 填家長基本資料：
   - 姓名、性別、Email（選填）、地址（選填）
3. 新增學員：點「+ 新增學員」，可一次加多筆兄弟姊妹。
   - 姓名、生日、性別、身分證字號（選填）、就讀學校
4. 送出 → 註冊成功，自動進入首頁。

> 之後再開 LIFF，只要輸入手機就直接登入，不用再註冊。

## 三、底部 4 個 Tab

### 1. 首頁
- 看到三個組別卡片：基礎、進階、菁英。
- 進行中的優惠會出現在橫幅。
- 點組別卡片進入「選場館」。

### 2. 我的課
- 4 個分頁：全部 / 待對帳 / 進行中 / 已結束。
- 每張課程卡顯示堂數進度條（已上 / 總堂數）。
- 點卡片進入「學習歷程」（看教練填的課前規劃 + 授課記錄）。

### 3. 聊天
- 跟教練／場館對話（Phase 4 上線後啟用）。

### 4. 我的
- 學員清單（可看每位學員的個資、課程歷程）。
- 推薦連結（MGM）：點「產生我的推薦連結」→ 複製或分享給朋友，朋友透過你的連結註冊並完成體驗課簽到後，你會自動拿到 9 折券。
- 登出。

## 四、報名一堂課（完整流程）
1. 首頁選組別（例：基礎）。
2. 選場館（例：板橋館）。
3. 看教練清單；資深教練有金色徽章；費用已套修課係數。
4. 點教練 → 進「報名頁」。
5. 勾選要上課的學員：
   - 自己的學員可直接勾選。
   - 1 對 2、1 對 3 課程：輸入合報家長手機 → 系統查到對方學員 → 勾選對方要合報的學員。
6. 折扣：
   - 系統會自動帶最佳優惠。
   - 若有折價券（例 `WELCOME10`）→ 輸入後按「套用」。
   - 折扣不適用會出現紅字提示。
7. 看到「銀行帳號」區塊 → 點一鍵複製 → 用網銀／ATM 轉帳。
8. 回到 LIFF → 填轉帳金額末 5 碼 → 確認摘要彈窗 → 送出。
9. 跳到「報名成功，等待對帳」頁。

> 場館人員會在 1–2 個工作日內對帳，狀態變「進行中」後就可以開始選上課時段。

## 五、選上課時間（Phase 2）
- 「我的課」→ 點該堂 → 進「選時段」日曆。
- 看到綠色格 = 教練可開課時段。
- 點選 → 確認 → 預約完成（會收到 LINE 推播提醒）。

## 六、簽到（Phase 2）
- 上課當天到場館 → 跟櫃檯說手機號碼 → 櫃檯在後台幫你完成簽到。
- 簽到成功後堂數進度會 +1。

## 七、學習歷程（每堂上完課可查）
- 「我的課」點課程卡 → 進「學習歷程」。
- 時間軸顯示每堂的：
  - 課前規劃（教練上課前發佈）
  - 授課記錄（教練下課後填寫，可能含照片／影片）
- 右上角「列印」可印成紙本給孩子帶回家複習。

## 八、期末評鑑
- 課程結束（或最後一堂簽到後）系統會推播 LINE 訊息給你：
  - 點訊息 → 進評鑑頁。
- 4 個維度 ★ 評分（教學專業、溝通態度、時間管理、整體滿意度）+ 文字回饋 + 是否願意續報。
- 7 天未填會自動再提醒一次。

## 九、推薦朋友（MGM）
1. 「我的」→ 推薦連結 → 產生 → 複製連結 / QR Code。
2. 朋友點連結註冊 + 完成體驗課簽到 → 系統自動：
   - 給朋友：報名時可用 `TRIAL50` 體驗課 5 折。
   - 給你：發 9 折券 `MGM***` 到 LINE，下次報名可用。
3. 在「我的」→ 我的推薦清單可看狀態：待註冊 / 已註冊 / 已體驗 / 獎勵已發放。

## 十、常見問題
| 問題 | 解法 |
|---|---|
| 開 LIFF 一片白 | 用 LINE 內開（不要用 Safari）；或重新整理 |
| 手機登入查不到 | 先去註冊；註冊過確認手機號碼 10 碼正確 |
| 折價券無效 | 檢查代碼大小寫、是否過期、是否限定組別／場館 |
| 銀行帳號複製不到 | 改長按手動複製 |
| 對帳一直沒過 | 隔一個工作日仍沒過 → LINE 場館客服 |
| 沒收到 LINE 推播 | 確認你已加場館官方帳號為好友且未封鎖 |
