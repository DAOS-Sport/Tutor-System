# 教練 使用手冊

## 一、開啟方式
- 在 LINE 內點教練專屬選單／連結 → 開啟 LIFF。
- LINE 內連結：`https://liff.line.me/<LIFF_ID_COACH>/coach`（`<LIFF_ID_COACH>` 由系統管理員在 LINE Console 建好教練端 LIFF App 後告知）。
- 備用網頁版（測試用）：`https://daos-tutoring-courses.replit.app/liff/coach`
- 第一次會要你輸入手機號碼 + 自動帶 LINE id_token，系統會把你的 LINE UID 綁到教練檔案（之後在 LINE 內開都會自動登入）。
- 登入有效期 12 小時，超過要重新打開 LIFF 自動續期。

> 安全限制：5 分鐘內登入失敗 5 次會被擋 5 分鐘，請聯絡管理員確認你的手機號是否在系統內。

## 二、底部 3 個 Tab

### 1. 今日（首頁）
- 顯示今天所有要上的課，依時間排序。
- 每堂課卡片有：
  - 學員名單、組別（1 對 1／1 對 2／1 對 3）、上課地點。
  - 「填課前規劃」按鈕。
  - 「填授課記錄」按鈕（上完課再填）。

### 2. 排課
- 週／月切換的總表。
- 已被學員預約的時段：顯示學員名字（不可改時間）。
- 空白時段：點「+」或框選 → 新增可上課時段。
- 衝堂保護：同時段重複新增會被系統擋下並提示。

### 3. 我的
- 編輯個人 bio（自我介紹）。
- 介紹圖：上傳、排序（拖動）、刪除。
- 改完 bio 或介紹圖後 → 點「送審」→ 等系統管理員核准才會在家長端看到新版本。
- 登出。

## 三、每堂課的標準流程

### 上課前（建議至少 1 天前）
1. 「今日」找到該堂 → 點「填課前規劃」進入 `LessonPlanFormPage`。
2. 5 個區塊：
   - 教學目標
   - 重點內容
   - 教材／道具
   - 評估方式
   - 給家長的提醒
3. 兩種按鈕：
   - 「儲存草稿」：只有你看得到，可以反覆修改。
   - 「發佈」：家長會立刻收到 LINE 通知 `coursePlanPublished`，看得到內容。

> 已發佈的課前規劃還可以改，改完按「再次發佈」會更新版本。

### 上完課後（當天填完最佳）
1. 「今日」找到該堂 → 點「填授課記錄」進入 `SessionRecordFormPage`。
2. 點預設標籤（系統有 4 大分類 × 16 個起始標籤）→ 自動把標籤對應的句子帶進文字框，再人工潤飾。
   - 也可以新增自己的「個人標籤」（只你看得到）。
3. 媒體上傳：拍照或從相簿挑（最多 50MB／檔），自動傳到 Replit Object Storage。
4. 「複製前一堂」：把上一次的記錄整段帶過來，再修改差異。
5. 兩種按鈕：
   - 「儲存草稿」：只你看得到。
   - 「Submit」：家長收到 LINE 通知 `sessionRecordPublished`，並寫入版本歷史（每次 submit 都會留版本，可在底部「版本記錄」回看）。

## 四、開放可上課時段（排課總表）
1. 「排課」→ 切到要開的那一週／月。
2. 框選或點「+」→ 設定起訖時間、可接受的組別。
3. 系統用資料庫 advisory lock 保證並發新增不會撞時段。
4. 想關閉某個尚未被預約的時段：點該時段 → 刪除。

> 已被學員預約的時段不能直接刪；要先請場館人員協助處理。

## 五、學員管理（Phase 3 範圍）
- 在「今日」或「排課」點任一堂 → 看學員清單 → 點學員可看：
  - 基本資料（含家長手機）
  - 過往上課紀錄與評鑑分數

## 六、考核與分數
- 系統管理員會在後台設「考核門檻」（例：平均評分 ≥ 4、教學評分 ≥ 4、續報率 ≥ 60%）。
- 你可以在「我的」看到自己過去 3 個月的：
  - 4 維平均分數
  - 月度趨勢
  - 家長文字評語
- 若連續低於門檻，系統管理員會找你談。

## 七、常見問題
| 問題 | 解法 |
|---|---|
| LIFF 進不去 | 確認在 LINE 內打開、手機號正確、未連續登入失敗 |
| 找不到今天的課 | 該堂可能還沒被學員預約；或被櫃檯改期 |
| 介紹圖一直沒上架 | 你只送審了，要等管理員在後台核准 |
| 媒體上傳失敗 | 檔案 > 50MB；改壓縮再傳 |
| 標籤庫沒有我要的 | 自己加「個人標籤」；或建議管理員新增系統標籤 |
| 簽到顯示時段衝突 | 你今天有兩堂時間重疊；找場館協調 |
