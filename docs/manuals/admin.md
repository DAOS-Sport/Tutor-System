# 系統管理員（admin）使用手冊

## 一、登入
- 網址：`https://daos-tutoring-courses.replit.app/admin`
- 帳號：`admin`（生產環境請改用實際發給你的帳號）
- 密碼：`ADMIN_BOOTSTRAP_PASSWORD` 環境變數設定的密碼（首次登入務必改）
- 登入有效期 7 天（記住裝置可常駐）

> 警告：若 `JWT_SECRET` 或 `ADMIN_BOOTSTRAP_PASSWORD` 沒設好，系統啟動會直接拒絕；發生時請聯絡技術窗口。

## 二、左側選單（13 頁全部可見）

### 概覽群組
- **Dashboard**：今日報名／待對帳數／進行中課程數／本月營收概覽。

### 系統設定群組（admin 限定）
- **系統設定 (F-A01)**：全域開關（簽到時間範圍、退費規則、預設多久未對帳自動取消等）。
- **員工管理 (F-A02)**：新增 / 編輯 / 停用員工帳號；指派角色（admin / manager / staff）與所屬場館。
- **場館設定 (F-A03)**：場館基本資料、銀行帳號、`line_token`（場館專屬 Messaging API token）。
- **課程介紹 (F-A04)**：三組別文案 + 主圖。

### 營運群組
- **待對帳 (F-M02)**：列出 `pending_payment` 報名 → 比對轉帳末 5 碼 → 確認 / 拒絕。
- **所有報名 (F-R02)**：可篩狀態 / 場館 / 關鍵字。
- **退課 (F-R04)**：選報名 → 看「退費試算」→ 必填理由 → 確認；自動寫 audit log。
- **今日課程 (F-R01)**：所有場館今日課程總表。
- **簽到驗證 (F-R03)**：手機 + 期次 → 找到報名 → 確認簽到 → 自動觸發 MGM 推薦獎勵。
- **退課復活 (F-M05)**：被取消的時段在期限內可一鍵復活回原報名。

### 行銷與優惠群組
- **優惠活動 (F-M07/F-A05)**：建立 → 送審 → 核准 → active；可建自動套用或折價券。
- **進行中優惠 (F-R05)**：唯讀清單，給其他角色查詢用。

### 學習歷程群組
- **標籤庫 (F-A08)**：4 大分類與系統標籤 CRUD。
- **教練考核報表 (F-M09)**：每位教練 4 維平均、月趨勢、家長文字評語。
- **考核門檻 (F-A09)**：設定平均分／教學分／續報率最低值與觀察月數（預設 3 個月）。
- **教練介紹審核 (F-C06)**：待審 / 已退回 / 已上架 三 tab。

## 三、典型操作場景

### A. 確認一筆對帳
1. 待對帳 → 找到該家長手機。
2. 比對「轉帳末 5 碼」與實際銀行進帳。
3. 點「確認對帳」→ 課程狀態變 `active`，家長收到 LINE 通知。
4. 對不上 → 點「拒絕」+ 理由 → 通知家長重傳。

### B. 處理退費
1. 所有報名 → 篩 `active` → 找該筆。
2. 點「退費」→ 系統算出退款金額（依已上堂數扣除）。
3. **必填**「退費理由」（會進 audit log）→ 確認。
4. 報名狀態變 `refunded`，家長收到 LINE 通知。

### C. 建立優惠活動
1. 行銷 → 優惠活動 → 新增。
2. 填名稱、類型（PERCENTAGE / FIXED_AMOUNT）、折扣值、適用組別、適用場館、起迄日。
3. 折價券：留空 = 自動套用；填代碼 = 需家長手動輸入（例 `WELCOME10`）。
4. 「儲存草稿」→「送審」→ 系統管理員（你或其他 admin）→「核准」→ 自動進入 active。
5. 退回需備註原因。

### D. 核准教練介紹（F-C06）
1. 學習歷程 → 教練介紹審核 → 待審 tab。
2. 點教練 → 預覽 bio + 介紹圖。
3. 「通過」→ 立刻上架，家長端可見新版本。
4. 「退回」→ 必填備註 → 教練在 LIFF 看到原因可修改重送。

### E. 檢查教練表現
1. 學習歷程 → 教練考核報表。
2. 看總覽（每位教練平均分、是否低於門檻會標紅）。
3. 點教練看詳細：4 維分數月趨勢圖 + 家長文字評語清單。

### F. 系統參數調校
1. 系統設定 → 改數值 → 儲存。
2. 場館設定：每加一個新場館要同步建 LINE Messaging Channel，把 token 填進來。
3. 員工管理：教練新增 / 離職時即時 stop / start。

## 四、排程任務（背景）
以下 cron 由系統自動跑，你可以在 Dashboard 看到統計：
- 每日 09:00：上課提醒 LINE 推播（24 小時內的課）
- 每日 10:00：期末評鑑邀請 + 7 天未填提醒
- 每日 02:00：資料庫備份（任務 #19 後）
- 每日 03:00：超時未對帳自動取消（依系統設定的天數）

## 五、安全與權限
- 全部寫入操作都會寫 `admin_enrollment_audit_logs`（誰、何時、原因）。
- staff 角色看不到 `line_token` 與銀行帳號欄位（系統強制過濾）。
- 你（admin）以外的角色無法呼叫 `PATCH /admin/staff` 或系統設定 endpoint，前後端雙重把關。

## 六、緊急狀況
| 情境 | 動作 |
|---|---|
| 員工離職 | 員工管理 → 停用（不可刪除，保留歷史 audit） |
| 場館 LINE token 過期 | 場館設定 → 該場館 → 重填新 token |
| 教練被申訴 | 教練考核報表 → 看評語；必要時把該教練介紹下架 |
| 系統登入不了 | 確認 `JWT_SECRET`、`ADMIN_BOOTSTRAP_PASSWORD` 在 Replit Secrets 有設 |
