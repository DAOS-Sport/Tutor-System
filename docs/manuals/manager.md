# 場館主管（manager）使用手冊

## 一、登入
- 網址：`https://daos-tutoring-courses.replit.app/admin`
- 帳號：由系統管理員建立，限定你所屬的場館（例如「板橋館主管」）
- 登入後右上角顯示你的姓名 + 場館

> 你看到的所有資料預設是你所屬場館的；若有跨館需求請找系統管理員協助。

## 二、左側選單（你看得到的頁面）
比 admin 少：系統設定、員工管理、場館設定（這三頁屬系統層級）。

### 概覽群組
- **Dashboard**：你場館今日報名、待對帳、進行中課程、本月營收。

### 營運群組（你的主要工作）
- **待對帳 (F-M02)**：你場館的待對帳清單。
- **所有報名 (F-R02)**：你場館全部報名（可看其他場館為唯讀）。
- **退課 (F-R04)**：執行退費。
- **今日課程 (F-R01)**：你場館今日課表。
- **簽到驗證 (F-R03)**：協助學員到場簽到。
- **退課復活 (F-M05)**：被取消時段一鍵復活。

### 設定群組（部分）
- **課程介紹 (F-M06)**：可改三組別文案 + 主圖（與 F-A04 共用同一份資料）。

### 行銷與優惠群組
- **優惠活動 (F-M07)**：你可以建立草稿並送審；核准要等系統管理員。
- **進行中優惠 (F-R05)**：唯讀。

### 學習歷程群組
- **教練考核報表 (F-M09)**：你場館教練的 4 維平均、月趨勢、文字評語。

## 三、每天該做的事

### 早上（開場館）
1. 看 Dashboard：今日有幾堂課、幾筆待對帳、幾筆異常。
2. 待對帳 → 比對昨天的轉帳 → 全部處理掉。
3. 今日課程 → 確認教練都已準備好（缺人馬上 LINE 教練）。

### 上課時段
1. 簽到驗證 → 學員到場 → 輸入手機 + 期次 → 確認。
2. 系統會自動：堂數 +1、發 MGM 獎勵（如有）。
3. 教練臨時請假 → 退課復活（看是否該時段已被取消）→ 或請系統管理員協助改期。

### 下班前
1. 待對帳剩餘的逐筆處理或回覆。
2. 看是否有家長申請退費 → 退課 → 必填理由 → 確認。

## 四、關鍵操作

### A. 對帳
1. 待對帳 → 點該筆。
2. 比對「轉帳末 5 碼」與實際銀行進帳。
3. 「確認」→ 自動 active + LINE 通知家長。
4. 「拒絕」+ 理由 → 通知家長重傳。

### B. 退費
1. 所有報名 → 篩 active → 該筆。
2. 點「退費」→ 看試算金額。
3. **必填**理由 → 確認 → 系統寫 audit log + 通知家長。

### C. 課程介紹維護
1. 課程介紹 → 點要改的組別。
2. 改文案、換主圖（上傳新圖會自動換）。
3. 儲存後立即生效，家長 LIFF 重整即可看到。

### D. 優惠活動
1. 行銷 → 優惠活動 → 新增。
2. 填內容 → 儲存草稿 → 送審。
3. 等系統管理員核准 → 自動 active。
4. 被退回會看到備註，修改後再次送審。

### E. 教練考核（觀察）
1. 學習歷程 → 教練考核報表。
2. 看你場館每位教練表現；低於門檻會標紅。
3. 把問題點與系統管理員一起討論處理（你無法改門檻或下架介紹）。

## 五、權限限制
- 你**無法**建立 / 修改員工帳號 → 找系統管理員。
- 你**無法**改場館銀行帳號或 LINE token → 找系統管理員。
- 你**無法**核准優惠或核准教練介紹 → 只能送審。
- 跨場館資料只能讀，不能寫。

## 六、常見問題
| 情境 | 動作 |
|---|---|
| 家長一直催對帳 | 確認待對帳清單 → 若銀行已進帳 → 立刻確認 |
| 學員臨時不能到 | 簽到驗證找該筆 → 改用 Phase 2 自助取消（或代請場館協調） |
| 教練今天請假 | LINE 教練、安排代課；後台請系統管理員協助改 schedule |
| 想看其他場館資料 | 只能讀；要操作要請系統管理員或對方場館主管 |
| 折價券想做臨時活動 | 行銷 → 新增 → 送審；急件直接 LINE 系統管理員加速核准 |
