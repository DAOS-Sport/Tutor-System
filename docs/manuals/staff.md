# 行政櫃檯（staff）使用手冊

## 一、登入
- 網址：`https://daos-tutoring-courses.replit.app/admin`
- 帳號：由系統管理員建立，固定綁你所屬場館
- 登入有效 7 天（櫃檯共用電腦每天下班建議登出）

## 二、你看得到的 4 頁
比其他角色精簡很多，因為櫃檯只負責現場接待與簽到。

| 頁面 | 用途 |
|---|---|
| Dashboard | 你場館今日課程、待簽到統計 |
| 所有報名（唯讀） | 查家長 / 學員資料；自動鎖在你場館 |
| 今日課程 | 你場館今日課表，依時段排序 |
| 簽到驗證 | 協助學員到場簽到 |

> 你**看不到**：系統設定、員工、場館、課程介紹、待對帳、退課、退課復活、優惠活動、學習歷程相關所有頁面。

## 三、每日工作流程

### 開門前 5 分鐘
1. 登入 → Dashboard 看今天總共幾堂、幾位學員。
2. 今日課程 → 列印或開著畫面，方便對照。

### 學員陸續到場
1. 進到「簽到驗證」頁。
2. 輸入學員家長手機（10 碼）+ 期次（哪一個課程）。
3. 系統比對：
   - 找到 + 該堂正在簽到時間範圍 → 顯示綠色「可簽到」按鈕 → 點「確認簽到」。
   - 找不到 → 顯示紅字「查無資料」→ 改用「所有報名」搜尋確認。
   - 不是今天的課 → 顯示橘色提示。
4. 簽到成功會看到綠色 toast；學員的「我的課」堂數進度自動 +1。

> 跨場館查詢一律會顯示「查無」（系統故意隔離），確保資料只在自家場館操作。

### 學員找不到資料 / 沒帶手機
1. 改去「所有報名」用學員姓名搜尋。
2. 找到後抄手機號碼回去簽到驗證輸入。
3. 還是找不到 → 該家長可能還沒對帳完成 → 請場館主管協助。

### 下班前
1. 簽到驗證頁掃一遍今日課表，確認沒漏簽。
2. 漏簽的學員 → 馬上聯絡家長確認 → 隔天補簽（場館主管處理）。
3. 登出。

## 四、不能做的事（會看到禁止頁面）

| 想做的事 | 應該找誰 |
|---|---|
| 對帳（家長轉帳了） | 場館主管 |
| 退費 | 場館主管 |
| 改學員資料 / 加學員 | 請家長自己在 LIFF 改；或場館主管協助 |
| 改場館銀行帳號 | 系統管理員 |
| 看教練評鑑 | 場館主管 |
| 建優惠活動 | 場館主管 |
| 簽到別場館學員 | 不行；請對方去自己的場館簽 |

## 五、簽到驗證的安全規則
- 只能簽自己場館的課，跨館一律 `found:false`。
- 簽到時間有範圍（系統設定，預設課前 30 分 ~ 課後 60 分），超過會被擋。
- 同一堂同一學員只能簽一次。
- 連續輸錯手機 5 次會被系統暫時 rate-limit，等 5 分鐘再試。

## 六、常見問題
| 情境 | 動作 |
|---|---|
| 學員忘記期次 | 在「所有報名」搜學員姓名找出來 |
| 系統說「不在簽到時間」 | 太早或太晚；請學員稍候或請主管手動處理 |
| 家長要改地址／電話 | 請家長自己進 LIFF 改；櫃檯改不了 |
| 看不到隔壁場館 | 正常，系統故意鎖定 |
| 簽到送出沒反應 | 重新整理頁面；網路問題請重連 Wi-Fi |
| 想看待對帳清單 | 你看不到；轉介給場館主管 |
