## 共通注意事項
- 後台手機（< 768px）無法切頁，請使用桌機或平板。
- 手機請用 LINE 內開啟 LIFF 連結，可享自動登入；用一般瀏覽器則需重新輸手機驗證。
- 系統時區為 Asia/Taipei，所有時間皆為台灣時間。
- 若操作中出現錯誤紅字 toast，請截圖反映給系統管理員。
