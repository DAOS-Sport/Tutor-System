已存在後端 API：
- POST /api/auth/parent-line-login { id_token }
  回傳可能包含：
  - { status: "logged_in", parent, token }
  - { status: "need_phone_binding", line_uid }
- POST /api/auth/parent-bind-phone { id_token, phone }
  回傳可能包含：
  - { status: "bound_and_logged_in", parent, token }
  - { status: "need_registration", line_uid, phone }
  - 409 LINE_ALREADY_BOUND_TO_OTHER_PHONE
  - 409 PHONE_ALREADY_BOUND_TO_OTHER_LINE
- POST /api/auth/parent-register-line { id_token, parent, students }
  回傳：
  - { status: "registered_and_logged_in", parent, token }
  - 409 LINE_ALREADY_REGISTERED
  - 409 PHONE_EXISTS_USE_BINDING
  - 其他驗證錯誤

本次需求：
家長端不應一開始就輸入手機登入，而是：
1. 家長打開 LIFF。
2. 前端取得 liff.getIDToken()。
3. 呼叫 /api/auth/parent-line-login。
4. 若 logged_in：直接 setParent 並進首頁。
5. 若 need_phone_binding：顯示手機綁定畫面。
6. 手機綁定成功：登入首頁。
7. 手機查無資料 need_registration：進入註冊畫面，手機預填。
8. 註冊送出時呼叫 parent-register-line，寫入 Ragic Z01 主表 + 子表格，成功後登入首頁。
9. 若 LINE 已綁其他手機或手機已綁其他 LINE，要顯示中文錯誤，不可繼續。
