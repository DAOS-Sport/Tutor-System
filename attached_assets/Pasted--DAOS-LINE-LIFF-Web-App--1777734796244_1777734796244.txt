你是一位資深的全端工程師，請幫我完成「個家教課程系統」的前端介面開發。

## 系統背景
- 公司：駿斯運動事業股份有限公司（夢想體育學院 DAOS）
- 平台：LINE LIFF Web App（手機優先）+ Web 後台
- 技術棧：React + TailwindCSS + Vite + LINE LIFF SDK
- 後端：Node.js + Express（已建置，API 路由在 server/routes/）

## 品牌色系（必須嚴格套用）
- 主色（深海藍）：#15316a → 用於 Header、主要按鈕、標題
- 輔助色1（青碧綠）：#31aeab → 用於次要按鈕、Active 狀態
- 輔助色2（草地綠）：#97bf36 → 用於成功狀態、正向提示
- 警示色（橘黃）：#e8a020 → 用於提醒、待處理
- 資深教練專屬（金色）：#c9a84c → 資深教練徽章
- 字型：Noto Sans TC（中文）+ Inter（英數）

## 使用者角色與入口
1. 學員/家長 → LINE LIFF（手機，從 LINE@ 進入）
2. 教練 → LINE LIFF（手機，從 LINE@ 進入）
3. 場館櫃檯 → Web 後台（桌機）
4. 場館主管 → Web 後台（桌機）

## 重要系統邏輯（開發時必須遵守）

### 課程購買流程
1. 選場館 → 選教練 → 選組別（1對1/1對2/1對3）
2. 若1對多：輸入同組另一家長手機 → 從系統列出該手機綁定的學員 → 選擇正確學員
3. 顯示該場館銀行帳號 + 一鍵複製帳號按鈕
4. 學員自行轉帳後，填入「轉帳末5碼」→ 送出報名
5. 狀態：待對帳 → 主管對帳確認後 → 立即自動開通

### 排課邏輯（v7 核心：教練開槽，學員選槽）
- 教練端：預先在「排課總表」開放可授課時段槽位（available）
- 學員端：只能從教練已開放的槽位中選擇，不可自行輸入時間
- 1對1：選槽後即時確認（不需等待）
- 1對多：選槽後同組其他家長需在1小時內確認（逾時視為同意）

### 教練分級顯示
- 一般教練：正常顯示，費用 = 定價
- 資深教練：金色徽章 +「含學習歷程服務」標註 + 費用 = 定價 × 該教練係數（120%～150%）

### 簽到機制
- 學員點擊簽到 → 顯示簽到結果畫面（出示給櫃檯查驗）
- 同期同組其他學員：自動連動顯示「已簽到（由XXX，HH:MM）」

## 開發規範

1. 所有頁面必須是手機優先設計（max-width: 390px 的手機螢幕）
2. 必須嚴格套用品牌色系，不可使用預設藍色或其他顏色
3. 所有 API 呼叫統一放在 client/liff/src/api/ 資料夾
4. 載入中狀態一律顯示 LoadingSpinner
5. API 失敗一律顯示 Toast 錯誤訊息
6. 所有金額顯示格式：NT$ 10,000（含千分位）
7. 日期顯示格式：2026/04/28（週一）
8. 手機號碼驗證：台灣格式 09xxxxxxxx
